# Modular & Packager

## 📌 Project Overview
Multi-Utility Toolkit is a Python project developed using a modular and package-based approach. It provides a menu-driven interface to perform date and time operations, mathematical calculations, random data generation, UUID generation, file handling, and module exploration.

## ✨  What Can It Do?

### 📅 1. Date and Time
- Display the current date and time.
- Calculate the difference between two dates.
- Display dates in different formats.
- Use a stopwatch.
- Run a countdown timer.

### 🧮 2. Mathematical Operations
- Calculate factorial.
- Calculate compound interest.
- Calculate sine, cosine, and tangent.
- Calculate the area of a circle, rectangle, and triangle.
- Calculate natural and base-10 logarithms.
- Convert kilometers to miles.
- Convert Celsius to Fahrenheit.

### 🎲 3. Random Data Generation
- Generate a random number within a selected range.
- Generate a list of random numbers.
- Generate a random password.
- Generate a demo OTP.
- Select random items from a user-provided dataset using random sampling.

### 🆔 4. UUID Generation
- Generate a UUID (Universally Unique Identifier).

### 📁 5. File Operations
- Create a text file.
- Write content to a text file.
- Read file content.
- Append new content to a file.
- Display a message when a file is empty or not found.

### 🔎 6. Explore Modules
- Explore available attributes of Python modules using `dir()`.
- Supported modules include `math`, `random`, `datetime`, `uuid`, and `time`.

## Project Structure

```text
📂 Modular_Packager/
├── README.md
├── main.py
└── utility_package/
    ├── __init__.py
    ├── math_utilities.py
    └── file_operations.py
```

## Requirements
- Python 3.x
- No third-party packages are required for the listed features; the project uses Python standard-library modules.

## ▶️ How to Run

1. Keep `main.py` and the `utility_package` folder in the same project directory.
2. Make sure `utility_package` contains `__init__.py`, `math_utilities.py`, and `file_operations.py`.
3. Open a terminal or command prompt in the project directory.
4. Run:

```bash
python main.py
```

If your system uses the `python3` command, run:

```bash
python3 main.py
```

## 🧭 How to Use
1. Run `main.py`.
2. Select an option from the main menu by entering its number.
3. Follow the prompts shown on the screen.
4. Use the relevant menu's **Back to Main Menu** option to return.
5. Select **Exit** to close the program.

## 📝 Notes
- When entering file names, the program adds `.txt` if it is not included.
- Random sampling selects the requested number of items from the entered dataset. The sample size must not exceed the number of available items.
- The OTP feature generates a demo OTP in the terminal; it does not send the OTP to a phone.
- This project is intended for educational use and demonstrates Python modules, functions, packages, loops, conditional statements, user input, and file handling.
